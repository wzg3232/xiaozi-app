小紫在 1.4.1 最终源代码
导出日期：2026-11-18（北京时间）；安卓/iOS 构建号：12。
品牌口号：小紫在，好友就在。

本包是当前最终交付版的开发工程。解压后直接进入含 package.json 的目录。
web：网页、客户端界面、紫色主题、品牌人物与字体素材。
server：账号、好友、群聊、消息、媒体、通话、小紫、企业平台和内部流程服务端。
native/android：安卓原生 Java、权限、后台通知、相机桥接及资源。
ios：Capacitor/Xcode 工程和已准备好的 1.4.1 资源。
dist：最后交付版已构建的网页资源；不含历史 APK 下载文件。
tests：现有自动化测试与测试音频；scripts：构建、测试和制作工作台脚本。
docs：本版交接、构建和部署说明；第三方许可证与字体许可随源码保留。

一、本地开发
安装 Node.js 24.15 或以上（包含 npm），在工程目录执行：
    npm ci --no-fund --no-audit
    npm run build
    npm start
浏览器打开 http://127.0.0.1:4200/，可注册新账号。
npm start 不会自动加载 .env；需要环境文件时使用：
    node --env-file=.env server/index.mjs
可从 .env.example 复制本地配置，不要将真实配置公开。
执行 npm test 运行现有测试；本次只导出源码，没有重新修改应用或重跑业务验收。
npm run demo 可在本地生成测试账号；正式环境不要启用。

二、网页及安卓
默认 npm run build 构建连接当前网页同源服务的资源。
发布手机包前，在 PowerShell 中指定正式 HTTPS 服务地址：
    $env:ICHAT_SERVER_URL='https://chat.pvdust.com'
    npm run build
安卓使用 scripts/build-android-native.ps1，依赖 JDK 21、Android Platform 36、
Build-Tools 36.0.0；分别配置 JAVA_HOME、ANDROID_HOME。
现有脚本要求维护者在 build-tools/ichat-demo.keystore 私下恢复原签名文件，
并校验既有签名指纹。签名私钥没有随源码提供；覆盖已安装的正式版必须沿用原签名。
随后执行 npm run android:build。不要把新签名包冒充可覆盖旧版的升级包。
官方已签名安卓包：https://chat.pvdust.com/downloads/xiaozi-1.4.1-android-public.apk

三、iOS
需要 Mac、Xcode 26 或以上和可用 Apple 签名条件。
在 Mac 工程目录执行 sh scripts/build-ios.sh，在 Xcode 配置团队后编译和归档。
详细步骤见 docs/iOS制作与安装说明.txt。本包不是可直接安装的 IPA，未做 iPhone 真机验收。

四、部署与接入
见 docs/服务端部署说明.txt、docs/1.4.1版本交接说明.txt 和企业平台与小紫接入说明.md。
账号数据库、用户上传、登录会话、API 密钥、私有配置、签名材料、SDK/JDK、
node_modules、录屏和历史安装包均未进入本包。通过 npm ci 安装锁定依赖。
真实 LLM 密钥与企业平台配置需要在服务器私下配置。
1.4.1 的业务图表仍使用既有固定数据；实际企业数据库尚未接入。
内部流程提交仍需配置真实审批人。产品界面文案不会改变这些接入状态。
接入说明沿用底层接口契约，其中旧模式切换入口已在 1.4.1 界面删除。

checksums.json 包含每个交付文件的 SHA256（清单本身除外）。
不要直接运行其他历史版本的升级脚本；本包不会自动修改当前线上服务。
